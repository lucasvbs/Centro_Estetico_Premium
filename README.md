# Centro Estético Premium

Landing page do Centro Estético Premium, centro de estética facial em Taguatinga Norte, Brasília-DF.

## Executar localmente

pnpm install
pnpm run dev

## Build

pnpm run build
pnpm run preview

## Antes de publicar

Atualize a constante WHATSAPP_NUMBER em src/App.tsx com o número oficial da clínica.

As imagens de resultados e do espaço interno ficam em public/assets.
